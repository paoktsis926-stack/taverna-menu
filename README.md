# Taverna Menu 2.0

Ψηφιακό μενού για την ταβέρνα «Μπαρμπούνια», με δημόσια προβολή, διαχείριση προϊόντων και κατηγοριών, ελληνικά/αγγλικά, αναζήτηση, QR και εκτυπώσιμο κατάλογο.

## Λειτουργίες
- Responsive δημόσιο μενού για κινητά, tablet και υπολογιστές.
- Εναλλαγή ελληνικών/αγγλικών και αναζήτηση προϊόντων.
- Διαχείριση κατηγοριών, προϊόντων, σειράς εμφάνισης, διαθεσιμότητας και τιμών.
- Στοιχεία αλλεργιογόνων σε ελληνικά και αγγλικά.
- Εκτύπωση καταλόγου σε A4 / αποθήκευση PDF, QR poster και table tents.
- Βασικά στατιστικά επισκεψιμότητας και ρυθμίσεις καταλόγου.

## Ρύθμιση
Απαιτείται Node.js 20 ή νεότερο.

Μεταβλητές περιβάλλοντος:
- `ADMIN_PASSWORD` — υποχρεωτική.
- `SESSION_SECRET` — προαιρετική μεταβλητή που χρησιμοποιείται από την υπάρχουσα εφαρμογή.
- `DB_PATH` — προαιρετική διαδρομή SQLite, π.χ. `/data/menu.db`.
- `BASE_URL` — προαιρετική δημόσια διεύθυνση, π.χ. `https://example.gr`.

Εκκίνηση:
```bash
npm install
ADMIN_PASSWORD='βάλε-κωδικό' npm start
```

Διαχείριση: `/admin`. Δημόσιο μενού: `/`.

**Σημείωση:** Το `npm run seed` αντικαθιστά τα υπάρχοντα προϊόντα και τις κατηγορίες με τα δεδομένα του `menu-seed.txt`. Μην το εκτελείς για συνηθισμένη εκκίνηση.
